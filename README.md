# Amarante - Salon & Beauty Culture Website (Next.js)

A 5-page premium marketing site for **Amarante**, a Colombo hair & skin studio.

## Stack

- **Next.js 14** (App Router)
- **Tailwind CSS** - full custom design system via 'tailwind.config.js'
- **Framer Motion** - scroll reveals, page/menu transitions, gallery lightbox, testimonials, FAQ accordion
